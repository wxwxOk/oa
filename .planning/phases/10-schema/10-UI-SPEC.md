## Grid Layout Contract

This section is specific to Phase 10 — defines the 12-column grid rendering rules.

### GridFormRenderer

| Property | Value |
|----------|-------|
| Grid system | CSS Grid, 12 equal columns |
| Column template | `grid-template-columns: repeat(12, 1fr)` |
| Gutter (column gap) | 16px |
| Row gap | 8px |
| Field placement | `grid-column: span {colSpan}` where colSpan is 1-12 |
| Overflow behavior | Fields whose cumulative colSpan exceeds 12 wrap to next implicit row |
| Container max-width | 100% of parent (no fixed max-width at renderer level) |
| Container padding | 16px |

### Mode Behaviors

| Mode | Interactive | Drag handles | Validation | Border style |
|------|-------------|-------------|------------|--------------|
| designer | disabled inputs | visible (drag_indicator icon, 16px, `--oa-text-tertiary`) | none | 1px solid `--oa-border`, 2px solid `--oa-focus-ring` when selected |
| fill | enabled inputs | hidden | active (Quasar rules) | 1px solid `--oa-border` |
| print | read-only values | hidden | none | 1px solid `--oa-border`, no hover/focus effects |

### FieldRenderer Mode Contract

| Mode | text/textarea/phone/date | radio/checkbox | signature |
|------|--------------------------|----------------|-----------|
| designer | QInput outlined dense disabled | QOptionGroup disabled | Placeholder box "签名区域" |
| fill | QInput outlined, v-model bound, rules active | QOptionGroup v-model bound | SignatureField interactive |
| print | Plain text value (no input chrome) | Selected option as text | Signature image (`<img>`) |

Source: CONTEXT.md D-06, D-07; existing `FormFieldRenderer.vue`, `DesignerCanvas.vue`

|-------------|---------------|
