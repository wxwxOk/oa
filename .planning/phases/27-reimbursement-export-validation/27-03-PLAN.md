<task id="27-03-02" type="auto">
  <name>Add permission-gated export toolbar action</name>
  <files>frontend/src/pages/ReimbursementPage.vue, frontend/src/pages/__tests__/ReimbursementPage.test.ts</files>
  <read_first>
    - `frontend/src/pages/ReimbursementPage.vue` for current toolbar, `currentFilters`, refresh/create actions and mobile layout.
    - `frontend/src/pages/ApprovalArchivePage.vue` for blob download implementation details.
    - `.planning/phases/27-reimbursement-export-validation/27-UI-SPEC.md` for labels, loading, feedback and negative contract.
    - `frontend/src/pages/__tests__/ReimbursementPage.test.ts` for source contract style.
  </read_first>
  <action>
    In `ReimbursementPage.vue`, add an export button in the existing header toolbar near refresh/create actions. Render it only when `auth.hasPerm('reimbursement:export')` is true. Desktop label should be `导出 Excel`; mobile can be an icon/round button but must keep `aria-label="导出报销 Excel"` and a tooltip. Bind loading/disable state to `store.exportLoading` so repeated clicks are prevented.

    Add `async exportReimbursements()` that calls `store.exportExcel(currentFilters.value)` and downloads the returned blob through `URL.createObjectURL`, a temporary `<a>`, `link.click()`, and `URL.revokeObjectURL()`. Use a clear filename such as `reimbursements-${new Date().toISOString().slice(0, 10)}.xlsx`. Always revoke the object URL after click, including failure paths where a URL was created.

    On success, show `Notify.create({ type: 'positive', message: 'Excel 导出已开始' })`. On failure, surface the oversize message `当前筛选结果超过导出上限，请缩小筛选范围后重试。` when the backend provides it, otherwise show `导出失败，请稍后重试。`. Keep error extraction simple and maintainable; do not introduce a broad error framework.

    Do not pass `reviewScope` to export. Do not use `window.open`, direct `/api/v1/reimbursements/export` URL construction, public links, `/approval/applications`, statistics dashboard copy, OCR, `发票验真`, payment, accounting or voucher UI.
  </action>
  <verify>
