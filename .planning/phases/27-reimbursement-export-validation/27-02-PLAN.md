    Create `backend/src/modules/reimbursement/reimbursement-export.service.ts`. Import `ExcelJS` and `BizError`.     Add small private format helpers only where needed: status label mapping for `DRAFT`, `DEPARTMENT_REVIEW`, `FINANCE_REVIEW`, `APPROVED`, `REJECTED`; review action result labels `通过`/`驳回`; date formatting stable enough for tests; and amount formatting without locale drift. Apply `sanitizeReimbursementExcelCell()` to every string cell, including comments, title, reason, payee info, remark and names.

  <action>
    Export `exportReimbursementsExcel(actor, filters, dependencies?)` from `reimbursement-export.service.ts`. Use dependency injection only for tests; production defaults should use the existing Prisma/service code path. Preserve only current list filters `status`, `category`, `dateFrom`, `dateTo`, and `keyword`; ignore incoming `page` and `size` and page through all matching rows with a small internal page size such as `100`.

    Reuse existing reimbursement filter normalization and visibility logic. If the existing list function already returns enough row/action data, call it with overridden `page`/`size`; otherwise extract a minimal shared helper from `reimbursement.service.ts` instead of copying filter/visibility logic. Keep service exports intentional and avoid broad refactors.

    Before workbook generation, reject totals above `MAX_REIMBURSEMENT_EXPORT_ROWS` with `new BizError('当前筛选结果超过导出上限，请缩小筛选范围后重试。', 400, 'REIMBURSEMENT_EXPORT_TOO_LARGE')`. Load all rows up to the total when within the cap. Include attachment count and action trail data needed by the workbook without exposing absolute paths.

    In workbook row construction, derive department result/person/time/comment from the latest action whose type is `DEPARTMENT_APPROVE` or `DEPARTMENT_REJECT`. Derive finance result/person/time/comment from the latest action whose type is `FINANCE_APPROVE` or `FINANCE_REJECT`. Latest means most recent `createdAt`; keep all fields from the same action row. Output final approval time from `completedAt` only when status is `APPROVED`; leave it blank for `REJECTED`, `DRAFT`, `DEPARTMENT_REVIEW` and `FINANCE_REVIEW`.
