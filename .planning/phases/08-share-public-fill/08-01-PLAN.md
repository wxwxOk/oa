   a) 在 FormTemplate 模型中新增以下字段（在 updatedAt 之前）：
   ```

   ```

   ```
   shareLinks   ShareLink[]
   ```

   c) 在文件末尾（FormTemplate 模型之后）新增两个模型：
   ```prisma
   model ShareLink {
     id          Int          @id @default(autoincrement())
     code        String       @unique
     templateId  Int
     template    FormTemplate @relation(fields: [templateId], references: [id])
     creatorId   Int
     creator     User         @relation(fields: [creatorId], references: [id])
     createdAt   DateTime     @default(now())
     submissions Submission[]

     @@index([templateId])
     @@index([creatorId])
   }

   model Submission {
     id             Int          @id @default(autoincrement())
     data           Json
     schemaVersion  Int
     submitterName  String?
     submitterPhone String?
     templateId     Int
     template       FormTemplate @relation(fields: [templateId], references: [id])
     shareLinkId    Int
     shareLink      ShareLink    @relation(fields: [shareLinkId], references: [id])
     createdAt      DateTime     @default(now())

     @@index([templateId])
     @@index([shareLinkId])
     @@index([createdAt])
   }
   ```

2. 修改 `backend/prisma/seed.ts`：在 PERMISSIONS 数组的表单模板模块部分末尾新增一条权限：
   ```typescript
   { code: 'form:template:share', name: '分享模板', module: 'form' },
   ```

3. 安装后端依赖：

   ```bash
   cd backend && npm install nanoid@5
   ```

4. 安装前端依赖：
   ```bash
   cd frontend && npm install qrcode && npm install -D @types/qrcode
   ```
