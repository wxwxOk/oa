## Surfaces

Phase 8 has TWO distinct UI surfaces with different layout contexts:

### Surface A: Internal (Admin) — within MainLayout

| Element | Description |
|---------|-------------|
| Share dialog | Modal on TemplatePage — shows share link URL + QR code + copy button |
| Identity toggle | Switch in FormDesignerPage property panel — `requireIdentity` boolean |

### Surface B: Public Fill Page — standalone, NO MainLayout

| Element | Description |
|---------|-------------|
| Route | `/f/:code` — `meta: { public: true }` |
| Layout | Standalone `q-layout` (like LoginPage pattern) — no sidebar, no topbar |
| Viewport | Mobile-first, card-style centered, max-width 640px |
| Background | `#F1F5F9` (slate-100) — light neutral, NOT the admin `--oa-bg` |
| Card | White `#FFFFFF`, border-radius 12px, shadow-2, padding 32px (mobile: 16px) |

## Interaction Contract

### Share Dialog Flow

1. User clicks "分享" button on a PUBLISHED template row (TemplatePage)
2. System calls POST `/api/share-links` to create/get share link
3. Dialog opens with full URL + QR code
4. "复制链接" button: `navigator.clipboard.writeText(url)` + `Notify.create({ type: 'positive', message: '链接已复制' })`
5. Dialog closes on backdrop click or "关闭" button

### Public Fill Page Flow

1. User opens `/f/:code` in browser
2. Page calls GET `/api/public/f/:code` to fetch template schema + metadata
3. Loading state: QSkeleton (3 field placeholders)
4. Error states:
   - Link not found (404): show error card "链接无效"
   - Template offline: show error card "该表单已停止收集"
5. Form renders with all fields from schema
6. Validation: Quasar native `rules` prop on each required field, triggered on submit
7. Submit: POST `/api/public/f/:code/submit` with form data
8. Submit button shows loading spinner during request
9. On success: replace form with success page (same route, state switch — NOT route navigation)
10. On error: `Notify.create({ type: 'negative', message: '提交失败，请稍后重试' })`

### Validation Rules

| Field | Rule |
|-------|------|
| Required text/textarea | `v => !!v?.trim() \|\| '此项为必填'` |
| Required radio | `v => v != null \|\| '请选择一项'` |
| Required checkbox | `v => v?.length > 0 \|\| '请至少选择一项'` |
| Required date | `v => !!v \|\| '请选择日期'` |
| Phone (identity) | `v => /^1\d{10}$/.test(v) \|\| '请输入有效手机号'` |
| Name (identity) | `v => !!v?.trim() \|\| '请输入姓名'` |
| Required signature | `v => !!v \|\| '请签名'` |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Touch targets | All buttons and inputs minimum 44px height on public fill page |
| Focus visible | 2px solid focus ring on all interactive elements (existing pattern) |
