**Part A: Create `DesignerRowEditor.vue`**

Extract the row-level editing from DesignerCanvas into a reusable component.

Props:
```typescript
const props = defineProps<{
  rows: SchemaRow[]
}>();
const emit = defineEmits<{
  'update:rows': [rows: SchemaRow[]]
  'select-field': [fieldId: string]
}>();
```

Template structure per row:
- Outer div `.editor-row` with row-drag-handle (drag_indicator 16px grey-5, 4px padding)
- VueDraggable for fields with `group: { name: 'fields', pull: true, put: true }`, handle `.field-drag-handle`, animation 150, filter `.row-remainder`, fallbackOnBody true, swapThreshold 0.65
- Each field: `.grid-canvas-field` with `.is-selected` class when `store.selectedFieldId === field.id`, gridColumn `span ${field.colSpan}`, click.stop emits `select-field`
- Field drag handle, FieldRenderer mode="designer", delete button, resize handle (when selected)
- Row remainder placeholder when remainingCols > 0
- Row delete button (hover-visible)

- Import `remainingCols`, `compressColSpan` from gridUtils
- `updateRowFields(rowIdx, newFields)` — mutates props.rows[rowIdx].fields, emits update:rows
- `onFieldAdd(rowIdx)` — compressColSpan for overflow
- `onFieldRemove(rowIdx)` — if row empty, splice from rows array, emit update:rows
- `startResize(e, field, rowIdx)` — pointer resize logic (same as current DesignerCanvas lines 178-200)
- `removeField(id)` — find field in rows, splice, clean empty rows, emit update:rows
- `deleteRow(rowIdx)` — splice row, emit update:rows

**Part B: Rewrite `DesignerCanvas.vue`**

Replace row-only rendering with item-level rendering.

Template structure:
```html
<div class="grid-canvas" @click.self="store.selectField(null)" @keydown="onKeydown" tabindex="0">
  <VueDraggable
    v-model="itemsList"
    handle=".item-drag-handle"
    :animation="150"
    ghost-class="item-ghost"
    class="canvas-items"
  >
    <template v-for="(item, idx) in schema.items" :key="itemKey(item, idx)">
      <!-- Row item -->
      <div v-if="item.type === 'row'" class="canvas-item-wrapper">
        <div class="item-drag-handle" aria-label="拖拽排序">
          <q-icon name="drag_indicator" size="16px" color="grey-5" />
        </div>
        <div class="item-content" style="flex:1">
          <!-- Single-row DesignerRowEditor -->
          <DesignerRowEditor
            :rows="[item]"
            @update:rows="(newRows) => updateSingleRow(idx, newRows)"
            @select-field="store.selectField($event)"
          />
        </div>
      </div>

      <!-- Group item -->
      <div v-else-if="item.type === 'group'" class="canvas-item-wrapper">
        <div class="item-drag-handle" aria-label="拖拽排序">
          <q-icon name="drag_indicator" size="16px" color="grey-5" />
        </div>
        <q-card flat bordered class="item-content group-card"
                :class="{ 'is-selected': store.selectedFieldId === item.id }"
                @click.stop="store.selectField(item.id)">
          <div class="group-header">{{ item.title }}</div>
          <div class="group-body">
            <DesignerRowEditor
              v-if="item.rows.length > 0"
              :rows="item.rows"
              @update:rows="(newRows) => updateGroupRows(idx, newRows)"
              @select-field="store.selectField($event)"
            />
            <div v-else class="group-empty-state">拖入字段到分组</div>
          </div>
        </q-card>
      </div>

      <!-- Dynamic Table item -->
      <div v-else-if="item.type === 'dynamic-table'" class="canvas-item-wrapper">
        <div class="item-drag-handle" aria-label="拖拽排序">
          <q-icon name="drag_indicator" size="16px" color="grey-5" />
        </div>
        <q-card flat bordered class="item-content table-card"
                :class="{ 'is-selected': store.selectedFieldId === item.id }"
                @click.stop="store.selectField(item.id)">
          <div class="table-header">{{ item.label }}</div>
          <div class="table-body">
            <div class="column-preview">
              <div v-for="col in item.columns" :key="col.key"
                   class="column-preview-cell"
                   :style="{ flex: col.width ?? 1 }">
                {{ col.label }}
              </div>
            </div>
          </div>
        </q-card>
      </div>
    </template>
  </VueDraggable>

  <div ref="bottomDropRef" class="canvas-drop-zone">
    <span>拖入字段创建新行</span>
  </div>

  <!-- Empty state -->
  <div v-if="schema.items.length === 0" class="empty-state">
    <span>从左侧拖入字段开始设计表单</span>
  </div>
</div>
```
