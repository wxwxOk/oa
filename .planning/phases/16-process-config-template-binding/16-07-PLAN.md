<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin UI -> template update API | UI can request mode changes that affect public collection and future internal approval submissions |
| Template list -> public sharing action | Operators must not accidentally create public links for internal approval templates |
| Router/user permissions -> binding controls | Users without approval binding permission must not see or operate binding controls |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T16-01 | Tampering | `TemplatePage.vue`, `FormDesignerPage.vue` | mitigate | Purpose badges, share action gating, and persistent disconnect confirmation prevent silent public-link breakage |
| T16-02 | Denial of Service | designer publish/binding controls | mitigate | Approval-required publish/save blocks when no enabled process is selected; backend remains source of truth |
| T16-06 | Elevation of Privilege | template binding UI | mitigate | Binding controls use `approval:template:bind`; template list keeps form permissions for existing actions |
</threat_model>
