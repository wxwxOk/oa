<action>
Create `frontend/src/types/reimbursement.ts`.

Define these exported types and interfaces:
- `ReimbursementStatus = 'DRAFT' | 'DEPARTMENT_REVIEW' | 'FINANCE_REVIEW' | 'APPROVED' | 'REJECTED'`.
- `ReimbursementAttachment` with `id`, `originalName`, `mimeType`, `size`, `uploaderId`, `createdAt`.
- `ReimbursementAction` with `id`, `actorId`, `actorName`, `type`, `nodeName`, `comment`, `signatureRelativePath`, `signatureMimeType`, `signatureSize`, `createdAt`.
- `ReimbursementRow` with `id`, `applicationNo`, `title`, `category`, `occurredAt`, `amount`, `reason`, `payeeInfo`, `remark`, `status`, `applicantId`, `applicantName`, `applicantDepartmentId`, `applicantDepartmentName`, `submittedAt`, `completedAt`, `attachmentCount`, `createdAt`, `updatedAt`.
- `ReimbursementDetail = ReimbursementRow & { attachments: ReimbursementAttachment[]; actions: ReimbursementAction[] }`.
- `ReimbursementListResponse` with `rows`, `total`, `page`, `size`.
- `ReimbursementListFilters` with `status`, `category`, `dateFrom`, `dateTo`, `keyword` string fields.
- `ReimbursementListRequest = Partial<ReimbursementListFilters> & { page?: number; size?: number }`.
- `ReimbursementWritePayload` with required `title`, `category`, `occurredAt`, `amount`, `reason` and optional nullable `payeeInfo`, `remark`.

Export these constants exactly:
- `REIMBURSEMENT_STATUSES = ['DRAFT', 'DEPARTMENT_REVIEW', 'FINANCE_REVIEW', 'APPROVED', 'REJECTED'] as const`.
- `REIMBURSEMENT_WRITE_PAYLOAD_KEYS = ['title', 'category', 'occurredAt', 'amount', 'reason', 'payeeInfo', 'remark'] as const`.
- `REIMBURSEMENT_LIST_FILTER_KEYS = ['status', 'category', 'dateFrom', 'dateTo', 'keyword'] as const`.
- `ALLOWED_REIMBURSEMENT_MIME_TYPES = ['image/jpeg', 'image/png', 'image/webp', 'application/pdf'] as const`.
- `MAX_REIMBURSEMENT_FILE_SIZE = 10 * 1024 * 1024`.
- `MAX_REIMBURSEMENT_ATTACHMENTS = 20`.

Export helper functions:
- `createEmptyReimbursementFilters(): ReimbursementListFilters`, returning all five filters as `''`.
- `reimbursementStatusLabel(status)` mapping `DRAFT` to `草稿`, `DEPARTMENT_REVIEW` to `部门初审`, `FINANCE_REVIEW` to `财务复核`, `APPROVED` to `已通过`, and `REJECTED` to `已驳回`.
- `reimbursementStatusColor(status)` mapping `DRAFT` to `grey`, `DEPARTMENT_REVIEW` to `orange`, `FINANCE_REVIEW` to `primary`, `APPROVED` to `positive`, and `REJECTED` to `negative`.
- `isDraftReimbursement(row)` returning true only when `row.status === 'DRAFT'`.
- `formatReimbursementDate(value?: string | null): string`, returning the first 10 characters for ISO/date-only input and `'-'` for empty/null.
- `formatReimbursementAmount(value?: string | number | null): string`, returning `¥${Number(value).toFixed(2)}` for finite values and `¥0.00` for empty/invalid values.
- `formatFileSize(size?: number | null): string`, returning `0 B` for empty/invalid, `${size} B` below 1024, `${(size / 1024).toFixed(1)} KB` below 1MB, and `${(size / 1024 / 1024).toFixed(1)} MB` at 1MB and above.
- `normalizeReimbursementPayload(payload)`, trimming string fields, converting blank `payeeInfo`/`remark` to `null`, preserving date-only `occurredAt`, and normalizing `amount` to `Number(payload.amount).toFixed(2)`.

Do not export `REIMBURSEMENT_CATEGORY_OPTIONS`, `REIMBURSEMENT_EXPORT_KEYS`, `REIMBURSEMENT_OCR_KEYS`, or `REIMBURSEMENT_REVIEW_ACTIONS`.

<action>
Create `frontend/src/stores/reimbursement.ts`.

Use `defineStore('reimbursement', ...)` and the authenticated `api` import from `src/boot/axios`. State must include:
- `rows: [] as ReimbursementRow[]`
- `total: 0`
- `page: 1`
- `size: 10`
- `filters: createEmptyReimbursementFilters()`
- `current: null as ReimbursementDetail | null`
- `loading: false`
- `detailLoading: false`
- `actionLoading: false`
- `uploadLoading: false`
- `downloadLoading: false`

Implement these actions with `try/finally` loading resets:
- `fetchList(filters?: ReimbursementListRequest)`: merge incoming filters with current filters, compute `page` and `size`, omit blank string filters, call `api.get('/reimbursements', { params })`, and store `rows`, `total`, `page`, `size`, `filters`.
- `fetchDetail(id: number)`: set `detailLoading`, call `api.get(`/reimbursements/${id}`)`, store and return `current`.
- `createDraft(payload: ReimbursementWritePayload)`: set `actionLoading`, call `api.post('/reimbursements', normalizeReimbursementPayload(payload))`, return the row/detail result.
- `updateDraft(id: number, payload: ReimbursementWritePayload)`: set `actionLoading`, call `api.put(`/reimbursements/${id}`, normalizeReimbursementPayload(payload))`, update `current` if it matches `id`, and return the result.
- `submitDraft(id: number)`: set `actionLoading`, call `api.post(`/reimbursements/${id}/submit`)`, update `current` if it matches `id`, and return the result.
- `uploadAttachment(id: number, file: File)`: set `uploadLoading`, create `const formData = new FormData()`, call `formData.append('file', file)`, then call `api.post(`/reimbursements/${id}/attachments`, formData)`, and return the attachment metadata.
- `previewAttachmentBlob(id: number, attachmentId: number)`: set `downloadLoading`, call `api.get(`/reimbursements/${id}/attachments/${attachmentId}/preview`, { responseType: 'blob' })`, and return `data as Blob`.
- `downloadAttachment(id: number, attachmentId: number)`: set `downloadLoading`, call `api.get(`/reimbursements/${id}/attachments/${attachmentId}/download`, { responseType: 'blob' })`, and return `data as Blob`.
- `deleteAttachment(id: number, attachmentId: number)`: set `actionLoading`, call `api.delete(`/reimbursements/${id}/attachments/${attachmentId}`)`, and remove the attachment from `current.attachments` if `current?.id === id`.

Do not call `/api/v1` directly; all paths must be relative to the existing axios base. Do not call `/approval/applications`, `/reimbursements/export`, or review endpoints.
</action>
