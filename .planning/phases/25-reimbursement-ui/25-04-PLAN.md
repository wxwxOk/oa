<action>
Create `frontend/src/pages/ReimbursementPage.vue`.

- Use `q-page padding`, `useRouter`, `useReimbursementStore`, `useAuthStore`, `useResponsive`, `Notify`, `ReimbursementStatusChip`, and `EmptyState`.
- On mount, call `store.fetchList()`.
- Header copy: title `我的报销`; subtitle `提交报销申请并追踪当前审核状态`; primary CTA `新建报销申请` routes to `/reimbursements/new` and is shown only when `auth.hasPerm('reimbursement:create')` or `v-perm="'reimbursement:create'"` is used.
- Desktop filters include exactly five live filter fields: `keyword`, `status`, `category`, `dateFrom`, and `dateTo`, plus buttons `查询` and `重置筛选`.
- Mobile filters use a bottom `q-dialog` sheet with draft filters and action `应用筛选`; live filters update only when `应用筛选` is clicked.
- Desktop list uses `q-table` with `row-key="id"`, server-side `@request`, `:rows-per-page-options="[10, 20, 50]"`, and columns for `applicationNo`, `title`, `category`, `amount`, `occurredAt`, `status`, `attachmentCount`, `applicantName`, `updatedAt`, and `actions`.
- Mobile list uses cards with class `reimbursement-card`, showing `title`, `applicationNo`, status chip, `category`, `amount`, `occurredAt`, `attachmentCount`, and `updatedAt`.
- Empty state uses `EmptyState` and copy `暂无报销申请` plus `可新建报销申请并上传发票或凭证。`; create CTA appears only with `reimbursement:create`.
- Error state copy must include `报销列表加载失败，请重试` and a retry action calling `store.fetchList()`.
- Row/card actions: `查看` routes to `/reimbursements/${row.id}`; `继续编辑` routes to `/reimbursements/${row.id}/edit` only when `isDraftReimbursement(row)` and create permission are true; `提交申请` is visible only for drafts with create permission, calls `store.submitDraft(row.id)`, shows `报销申请已提交，等待部门初审`, and refreshes the list.
- Keep all API calls inside `useReimbursementStore`; the page must not import `api` or call `api.get`, `api.post`, `api.put`, or `api.delete`.
- Do not include category dictionaries, export, OCR, review approval/rejection actions, signature capture, `/approval/applications`, or direct attachment URLs.
</action>
