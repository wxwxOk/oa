<action>
Create `frontend/src/types/__tests__/reimbursement.test.ts`.

- Import the planned module namespace from `../reimbursement` plus named planned exports: `REIMBURSEMENT_STATUSES`, `REIMBURSEMENT_WRITE_PAYLOAD_KEYS`, `REIMBURSEMENT_LIST_FILTER_KEYS`, `ALLOWED_REIMBURSEMENT_MIME_TYPES`, `MAX_REIMBURSEMENT_FILE_SIZE`, `MAX_REIMBURSEMENT_ATTACHMENTS`, `createEmptyReimbursementFilters`, `formatReimbursementDate`, `formatReimbursementAmount`, `formatFileSize`, `reimbursementStatusLabel`, `reimbursementStatusColor`, `isDraftReimbursement`, and `normalizeReimbursementPayload`.
