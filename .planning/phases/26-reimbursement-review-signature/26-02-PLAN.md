    Extend `reimbursement.service.ts` with these exports: `ReimbursementReviewDecision = 'approve' | 'reject'`, `ReimbursementReviewStage = 'department' | 'finance'`, `ReimbursementReviewInput = { comment?: unknown; signature?: File | null }`, `canDepartmentReviewReimbursement`, `canFinanceReviewReimbursement`, `normalizeReimbursementReviewInput`, `listDepartmentReviewReimbursements`, `listFinanceReviewReimbursements`, `approveDepartmentReimbursement`, `rejectDepartmentReimbursement`, `approveFinanceReimbursement`, and `rejectFinanceReimbursement`.

    Implement `canDepartmentReviewReimbursement(actor, application, actorDepartmentId?)` so it returns true only when `application.status === 'DEPARTMENT_REVIEW'`, the actor has `reimbursement:department-review` or role `ADMIN`, and for non-admin reviewers `actorDepartmentId != null && actorDepartmentId === application.applicantDepartmentId`. It must return false for `reimbursement:list` alone. Implement `canFinanceReviewReimbursement(actor, application)` so it returns true only when `application.status === 'FINANCE_REVIEW'` and the actor has `reimbursement:finance-review` or role `ADMIN`; it must return false for `APPROVED`, `REJECTED`, `DRAFT`, `DEPARTMENT_REVIEW`, and `reimbursement:list` alone.

    Implement `normalizeReimbursementReviewInput(input, decision)` as follows: trim `comment`; for `decision === 'approve'`, return blank comments as `null`, require `input.signature instanceof File`, and call `assertAllowedReimbursementSignature({ mimeType: signature.type, size: signature.size, originalName: signature.name })`; for `decision === 'reject'`, require a non-empty trimmed comment and always return `signature: null`. Throw `new BizError('审核通过必须提供手写签名', 400, 'REIMBURSEMENT_SIGNATURE_REQUIRED')` when approve has no file, and `new BizError('驳回原因不能为空', 400, 'REIMBURSEMENT_REJECT_COMMENT_REQUIRED')` when reject comment is blank.

    Implement `listDepartmentReviewReimbursements(actor, input = {})` by normalizing pagination/filter input, loading `actorDepartmentId`, rejecting unauthorized actors with `new BizError('缺少部门初审权限', 403, 'REIMBURSEMENT_DEPARTMENT_REVIEW_FORBIDDEN')`, forcing `status: 'DEPARTMENT_REVIEW'`, forcing `applicantDepartmentId: actorDepartmentId` for non-admin actors, applying existing category/date/keyword filters, ordering by `updatedAt: 'desc'`, and returning `{ rows, total, page, size }`. Implement `listFinanceReviewReimbursements(actor, input = {})` similarly, but force `status: 'FINANCE_REVIEW'` and reject unauthorized actors with `new BizError('缺少财务复核权限', 403, 'REIMBURSEMENT_FINANCE_REVIEW_FORBIDDEN')`.

    Implement the four action functions using a shared internal helper if desired, but expose the exact functions above. For `approveDepartmentReimbursement`, normalize with decision `approve`, set next status `FINANCE_REVIEW`, action type `DEPARTMENT_APPROVE`, node name `REIMBURSEMENT_DEPARTMENT_REVIEW_NODE`, and no `completedAt`. For `rejectDepartmentReimbursement`, normalize with decision `reject`, set next status `REJECTED`, action type `DEPARTMENT_REJECT`, node name `REIMBURSEMENT_DEPARTMENT_REVIEW_NODE`, and `completedAt = new Date()`. For `approveFinanceReimbursement`, normalize with decision `approve`, set next status `APPROVED`, action type `FINANCE_APPROVE`, node name `REIMBURSEMENT_FINANCE_REVIEW_NODE`, and `completedAt = new Date()`. For `rejectFinanceReimbursement`, normalize with decision `reject`, set next status `REJECTED`, action type `FINANCE_REJECT`, node name `REIMBURSEMENT_FINANCE_REVIEW_NODE`, and `completedAt = new Date()`.

    For approve actions, generate `storedName = getSafeReimbursementSignatureStoredName()`, build `relativePath = buildReimbursementSignatureRelativePath(id, actionType, storedName)`, write the file with `writeReimbursementFile(relativePath, signature)` before the DB transaction, and delete it in a catch block with `deleteReimbursementFile(relativePath)` if the transaction fails. In the DB transaction, load the current application, enforce the stage-specific `canDepartmentReviewReimbursement` or `canFinanceReviewReimbursement` predicate, call `assertReimbursementTransition(application.status, nextStatus)`, update `status` and `completedAt`, and append `reimbursementAction.create()` with `actorId`, `actorName`, `type`, `nodeName`, `comment`, and signature metadata `{ signatureRelativePath: relativePath, signatureMimeType: signature.type, signatureSize: signature.size }`. Reject actions append null signature metadata. Return the updated application row.
