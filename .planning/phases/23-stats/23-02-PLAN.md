# Phase 23 Plan 02: Visit Stats Frontend Panel and Page Integration

<objective>
Add the `visit:stats`-gated statistics experience to the existing `/visits` page using the enriched backend DTO from Plan 23-01, without adding export, route or BI workflow scope.
</objective>

<context>
This plan consumes the backend stats contract from Plan 23-01. It extends the visit frontend types and Pinia store, creates a dedicated stats panel component using existing Quasar + vue-chartjs patterns, then wires the panel into `VisitPage.vue` behind the `visit:stats` permission.
</context>
