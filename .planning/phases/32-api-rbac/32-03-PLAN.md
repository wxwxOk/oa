<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser -> /admin/channel-partners | ADMIN clients (or any user with user:* permissions) create/manage partner accounts; partners must NOT have user:* and therefore cannot reach these endpoints. |
| route body -> Prisma | Strict TypeBox `additionalProperties: false`; password is hashed before write; status changes only through dedicated `/disable` and `/enable` paths. |
| recipient lookup -> assertRecipientCanReceivePushes | Untrusted `primaryRecipientId` validated before write to prevent binding a disabled or partner-role user as a recipient. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-03-PARTNER-PRIV-ESC | E | partner role granted by admin | mitigate | Service forces CHANNEL_PARTNER role via direct lookup of the seeded role; no body-controlled role assignment. |
| T-32-03-MASS-ASSIGN | T | create/patch endpoints | mitigate | Strict TypeBox bodies; status, departmentId, roleIds NOT in writable shape. |
| T-32-03-RECIPIENT-MISCONF | T | binding step | mitigate | `assertRecipientCanReceivePushes` rejects DISABLED users and CHANNEL_PARTNER users. |
| T-32-03-DISABLE-DATALOSS | T | disable lifecycle | mitigate | Status-only toggle; no deletion of ChannelPush, ChannelPushAttachment, ChannelPushReviewAction, ChannelPartnerProfile rows. Asserted by service test (Task 1) negative. |
| T-32-03-WEAK-PWD | E | partner password | mitigate | TypeBox enforces minLength 8; bcrypt cost 10 (matches existing admin seed). Password rotation flow deferred. |
| T-32-03-RBAC-LEAKAGE | I | list response | mitigate | `serializeChannelPartner` excludes password and role array; only the bound primary recipient (id, realName, dept) is returned. |
| T-32-03-USERNAME-ENUM | I | create endpoint | accept | Prisma `@unique` on User.username surfaces a constraint error on duplicate; admin-only access makes enumeration low-impact. Documented and accepted. |

Block on `high`. T-32-03-USERNAME-ENUM is the only `accept` and is justified by admin-only access.
</threat_model>
