## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend service -> PostgreSQL | Approval truth crosses into persistent storage; partial writes or missing constraints corrupt workflow history |
| Admin-configured process -> runtime application | Future process edits must not change historical application meaning |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-02 | Tampering | approval schema relations | mitigate | Model task/action/timeline rows with foreign keys to application and indexed status fields; require Prisma transaction use in later service plan |
| T-15-03 | Tampering | historical snapshots | mitigate | Persist `schemaSnapshot`, `processSnapshot`, `templateName`, `templateVersion`, `applicantName`, `applicantDepartmentName` on `ApprovalApplication` |
| T-15-05 | Repudiation | action/timeline history | mitigate | Use append-only `ApprovalAction` and `ApprovalTimelineEvent` tables with no service update/delete tasks in this phase |
</threat_model>
