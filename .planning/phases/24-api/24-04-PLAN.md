Export `ALLOWED_REIMBURSEMENT_MIME_TYPES = ['image/jpeg', 'image/png', 'image/webp', 'application/pdf']`, `MAX_REIMBURSEMENT_FILE_SIZE = 10 * 1024 * 1024`, and `MAX_REIMBURSEMENT_ATTACHMENTS = 20`.

    Export `reimbursementExtensionForMimeType(mimeType: string)` mapping `image/jpeg` to `.jpg`, `image/png` to `.png`, `image/webp` to `.webp`, and `application/pdf` to `.pdf`; throw `new BizError('不支持的报销附件类型', 400, 'REIMBURSEMENT_FILE_TYPE_NOT_ALLOWED')` for anything else.     Export `getSafeReimbursementStoredName(originalName: string, mimeType: string)` returning `${nanoid(16)}${reimbursementExtensionForMimeType(mimeType)}` and never using the original basename. Export `getReimbursementUploadRoot()` resolving `process.env.REIMBURSEMENT_UPLOAD_DIR ?? path.join(process.cwd(), 'uploads', 'reimbursements')`. Export `resolveSafeReimbursementPath(relativePath: string)` that rejects absolute paths, resolves the path under the upload root, and throws `new BizError('报销附件路径无效', 400, 'INVALID_REIMBURSEMENT_FILE_PATH')` when the resolved path is outside the root.

    Export `buildReimbursementRelativePath(applicationId: number, storedName: string)` returning `${applicationId}/${storedName}`. Export `writeReimbursementFile(relativePath: string, file: File)` that creates the parent directory and writes using `await Bun.write(absolutePath, file)`. Export `deleteReimbursementFile(relativePath: string)` that uses `rm(absolutePath, { force: true })`. Export `buildReimbursementPreviewHeaders({ mimeType, originalName })` returning `Content-Type` and `Content-Disposition` with `inline; filename="<sanitized>"`. Export `buildReimbursementDownloadHeaders({ mimeType, originalName })` returning `Content-Type` and `Content-Disposition` with `attachment; filename="<sanitized>"`. Sanitize header filenames by removing `\r`, `\n`, slash and backslash characters; `invoice\r\n.pdf` must become `invoice.pdf`.
