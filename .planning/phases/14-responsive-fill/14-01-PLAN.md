@media (max-width: 1023px) {
  .grid-row {
    grid-template-columns: 1fr !important;
    gap: 12px 0;
  }
  .grid-form .grid-row :deep(.q-field__control) {

  }

**GroupRenderer.vue** — append to existing `<style scoped>` block:
```css
@media (max-width: 1023px) {
  .grid-row {
    grid-template-columns: 1fr !important;
    gap: 12px 0;
  }
  .group-body .grid-row :deep(.q-field__control) {
    min-height: 44px;
  }
}
```

The `!important` is needed because inline `gridColumn: span N` on children is harmless in a 1-column grid (CSS Grid auto-clamps), but the grid-template-columns override must win over any potential specificity issues.

The `min-height: 44px` on `.q-field__control` ensures iOS HIG touch target compliance (D-09).

Do NOT modify any template or script code in either file. CSS-only changes.
