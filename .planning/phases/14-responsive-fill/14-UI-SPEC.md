## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline padding, icon gaps |
| sm | 8px | Grid row gap (vertical), compact spacing |
| md | 16px | Default element spacing, grid column gap, container padding (mobile), group body padding |
| lg | 24px | Tablet card padding |
| xl | 32px | PC card padding |
| 2xl | 48px | Not used this phase |
| 3xl | 64px | PC wrapper vertical padding (existing `padding: 64px 0`) |

Exceptions:
- 12px: Mobile field vertical gap (D-09), sticky submit button padding
- 44px: iOS HIG touch target min-height on mobile inputs (D-09)

## Interaction Contract

### PC Layout (>= 1024px)

| Element | Behavior |
|---------|----------|
| Container | maxWidth: 960px, centered, padding: 64px 0 |
| Grid rows | `grid-template-columns: repeat(12, 1fr)`, gap: 8px 16px |
| Fields | `gridColumn: span ${colSpan}` (unchanged) |
| Groups | Title bar + 12-col grid body (unchanged) |
| Dynamic table | HTML `<table>` (unchanged) |
| Submit button | Full-width inside QCardSection (unchanged) |

### Mobile Layout (< 1024px)

| Element | Behavior |
|---------|----------|
| Container | maxWidth: 100%, padding: 16px |
| Grid rows | `grid-template-columns: 1fr`, gap: 12px 0 |
| Fields | Full width, ignore colSpan; min-height 44px on inputs |
| Groups | Title bar preserved, fields single-column, no collapse (D-04) |
| Dynamic table | QExpansionItem cards (see Card Layout below) |
| Submit button | `position: sticky; bottom: 0` with shadow bar |

### Mobile Card Layout (DynamicTableFill)

| Element | Spec |
|---------|------|
| Wrapper | QCard flat bordered, same as existing |
| Card per row | QExpansionItem, v-model bound to ref(true) per row |
| Card title | "第 {N} 行" via `<template #header>` slot |
| Delete button | QBtn flat dense round, icon="delete_outline", color="negative", size="xs", in header `<q-item-section side>`, @click.stop prevents expand toggle |
| Card body | QCardSection, fields stacked vertically: label div + input control |
| Field label | 14px/600, color: var(--oa-text-secondary) |
| Field input | Full width, min-height 44px |
| Add row button | QBtn flat dense, icon="add", label="添加行", color="primary", full width, border-top |
| Default state | All cards expanded (D-06) |
| Collapse animation | QExpansionItem built-in height transition (Claude's discretion) |

### Sticky Submit Button (Mobile)

| Property | Value |
|----------|-------|
| position | sticky |
| bottom | 0 |
| background | #FFFFFF (var(--oa-surface)) |
| padding | 12px 16px |
| padding-bottom | calc(12px + env(safe-area-inset-bottom, 0px)) |
| box-shadow | 0 -2px 8px rgba(0, 0, 0, 0.1) |
| z-index | 10 |
| border-radius | 0 0 8px 8px (match card bottom corners) |
