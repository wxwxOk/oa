<action>
Create `frontend/src/types/visit.ts`.

- Define `VisitRow`, `VisitDetail`, `VisitCreator`, `VisitListResponse`, `VisitListFilters`, `VisitFilterOptions`, and `VisitWritePayload`.
- Export `VISIT_WRITE_PAYLOAD_KEYS` with exactly these 15 fields: `name`, `age`, `education`, `gender`, `channelPartner`, `consultant`, `receptionStatus`, `receptionist`, `receptionDate`, `consultationStatus`, `statusCategory`, `statusDescription`, `trialStatus`, `solution`, `trialDate`.
- Export `VISIT_LIST_FILTER_KEYS` with `keyword`, `channelPartner`, `consultant`, `receptionist`, `receptionStatus`, `consultationStatus`, `statusCategory`, `dateFrom`, `dateTo`.
- Export `VISIT_FILTER_OPTION_KEYS` for the six backend distinct arrays.
- Export `createEmptyVisitFilters(): VisitListFilters`, returning all string filters as `''`.
- Export `formatVisitDate(value?: string | null): string`, returning the first 10 characters for ISO/date-only values and `'-'` for empty values.
- Export `normalizeVisitPayload(payload: VisitWritePayload): VisitWritePayload`, trimming `name`, preserving numeric `age`, and converting blank optional string/date fields to `null`.
- Do not add import/export/stats constants or helpers.
</action>

<action>
Create `frontend/src/stores/visit.ts`.

- Follow existing per-feature store style with `defineStore('visit', ...)`.
- State must include `rows`, `total`, `page`, `size`, `filters`, `filterOptions`, `current`, `loading`, `detailLoading`, and `actionLoading`.
- Implement `fetchList(filters?)`: merge incoming filters with current state, send only non-empty filter params plus `page` and `size`, call `api.get('/visits', { params })`, and store response list metadata.
- Implement `fetchFilterOptions()` with `api.get('/visits/filter-options')`.
- Implement `fetchDetail(id)` with `api.get(`/visits/${id}`)` and store `current`.
- Implement `createVisit(payload)`, `updateVisit(id, payload)`, and `deleteVisit(id)` with `POST /visits`, `PUT /visits/:id`, and `DELETE /visits/:id`.
- Use `try/finally` for every loading flag.
</action>
