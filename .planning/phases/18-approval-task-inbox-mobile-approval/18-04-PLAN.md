| list page interactions → store/API | UI filters and actions must preserve the task-centric security model and avoid unsafe quick actions |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-18-12 | T | inbox list actions | mitigate | Keep list actions limited to view/detail navigation; do not add inline approve/reject controls that bypass confirmation flows |
| T-18-13 | I | handled-history presentation | mitigate | Label handled results from task status and keep `CANCELED` out of the default handled bucket to avoid misrepresenting system-closed tasks as user actions |
