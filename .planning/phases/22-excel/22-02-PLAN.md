<action>
Create `frontend/src/components/visit/VisitImportDialog.vue`.

Implement this component contract:

- Props: `modelValue: boolean`.
- Emits: `update:modelValue` and `imported` with `VisitImportResponse`.
- Use `useResponsive()` and set the Quasar `q-dialog` `:maximized="isMobile"`.
- Render toolbar title `导入 Excel` and close button text/aria `关闭导入弹窗`.
- Use a Quasar file control or native file input that accepts `.xlsx,.xls` and shows selected filename.
- On file selection, use `FileReader`, `reader.readAsArrayBuffer(file)`, `XLSX.read(arrayBuffer)`, `workbook.SheetNames[0]`, `workbook.Sheets[sheetName]`, and `XLSX.utils.sheet_to_json(sheet, { header: 1 })`.
- Pass the resulting array-of-arrays and `file.name` into `parseVisitImportRows(rows, file.name)`.
- Store and render `VisitImportPreview` including file name, `headerValid`, `validRows.length`, `invalidRows.length`, `duplicateWarnings.length`, `headerErrors`, valid row preview, invalid row errors and duplicate warning rows.
- Confirm button label `确认导入有效行`; enable it only when `preview.headerValid === true` and `preview.validRows.length > 0`.
- On confirm, call `useVisitStore().importVisits(preview.validRows.map((row) => row.payload))`.
- On success, show positive `Notify` text containing `导入成功` and `createdCount`, emit `imported`, reset local file/preview state and close the dialog.
- On failure, keep the dialog open with the existing preview state and show negative `Notify` text containing `导入失败`.
- Do not show or implement `导出 Excel`, `统计`, `/visits/stats`, backend upload, template download, automatic merge or automatic skip actions.
</action>
