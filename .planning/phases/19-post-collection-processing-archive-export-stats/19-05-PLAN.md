## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client->archive route | Route payloads are untrusted and must not contain trusted source/actor/form-data fields. |
| archive service->source records | Service combines approval and collection sources under different permissions. |
| archive service->audit stores | Operations write current metadata and append-only audit events transactionally. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-IDOR | I/E | `archive.service.ts` | mitigate | Resolve source records server-side and apply approval department/all or collection-list permissions for list/detail/action. |
| T-19-TAMPER | T | `archive.route.ts` | mitigate | TypeBox bodies use `additionalProperties: false`; actor/source/form data derive from JWT and DB. |
| T-19-AUDIT | R/T | `ArchiveEvent` and approval timelines | mitigate | Every tag/note/edit/processing write appends an archive event; approval notes/marks/edits also append approval events. |
| T-19-CSV-INJECTION | T/I | archive service | accept | No spreadsheet generation in this plan; export plan 19-07 mitigates. |
| T-19-EXPORT-DOS | D | archive service | accept | No export generation in this plan; export plan 19-07 mitigates. |
