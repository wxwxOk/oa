| approval transaction->notification table | Workflow state changes create notification rows inside the same database transaction. |

| T-19-AUDIT | R/T | workflow hooks | accept | Notifications are not audit source of truth; approval events remain unchanged. |
| T-19-CSV-INJECTION | T/I | notifications | accept | No export surface in this plan. |
