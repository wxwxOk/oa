## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client->archive API | Authenticated staff submit filters and operation payloads for two source record types. |
| archive API->Prisma | Server applies source-specific permissions before reading or mutating operational metadata. |
| approval workflow->notifications | Transactional task/status changes create user-scoped notification rows. |
| archive API->Excel | Server transforms user-controlled form strings into spreadsheet cells. |
