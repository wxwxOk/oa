## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI->archive store | User-controlled filters and operations are sent to backend action endpoints. |
| detail DOM->PDF | Browser captures printable DOM; it must not mix formal and processing content ambiguously. |
| route/menu visibility->backend auth | Client-side permissions hide UI but backend remains authoritative. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-IDOR | I/E | archive routes/menu | mitigate | Use `permAny` only for navigation; backend plans enforce actual source visibility. |
| T-19-TAMPER | T | detail operation dialogs | mitigate | UI sends only operation payloads and requires reason/change before correction submit. |
| T-19-AUDIT | R/T | detail history/timeline | mitigate | UI exposes field correction history and processing timeline from backend append-only events. |
| T-19-CSV-INJECTION | T/I | export button | mitigate | UI calls backend Excel endpoint; backend plan sanitizes cells. |
| T-19-EXPORT-DOS | D | export button | mitigate | Button disables during export and surfaces backend row-cap copy. |
| T-19-NOTIFICATION-LEAK | I | archive UI | accept | Notifications are not touched in this plan. |
| T-19-DATA-SEPARATION | T/I | detail printable/processing sections | mitigate | UI separates `正式提交内容` from `后续处理信息` with explicit copy. |
</threat_model>
