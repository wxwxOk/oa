# Requirements Archive: v1.1 自定义表单收集

**Archived:** 2026-04-20
**Status:** SHIPPED
**Original defined:** 2026-04-20

## v1.1 Requirements (All Complete)

### 模板管理

- [x] **TMPL-01**: 用户可创建表单模板，定义模板名称和描述
- [x] **TMPL-02**: 用户可编辑和删除自己创建的表单模板
- [x] **TMPL-03**: 模板创建/编辑/删除受 RBAC 权限控制
- [x] **TMPL-04**: 用户可发布/下线模板，下线后分享链接不可填写
- [x] **TMPL-05**: 修改已发布模板时自动保存 schema 版本，已收集数据不受影响

### 表单设计器

- [x] **DSGN-01**: 用户可通过拖拽方式添加和排序表单字段
- [x] **DSGN-02**: 支持基础字段类型：文本、多行文本、单选、多选、日期、手机号
- [x] **DSGN-03**: 支持手写签名字段（Canvas 签名板）
- [x] **DSGN-04**: 用户可配置字段属性：必填、提示文字、选项列表
- [x] **DSGN-05**: 设计器提供实时预览

### 分享与填写

- [x] **SHARE-01**: 用户可为已发布模板生成唯一分享链接，记录分享人和时间
- [x] **SHARE-02**: 分享链接可生成二维码供扫码填写
- [x] **SHARE-03**: 外部人员通过浏览器打开链接免登录填写表单
- [x] **SHARE-04**: 模板可配置是否要求填写者提供身份信息（如姓名/手机号）
- [x] **SHARE-05**: 填写者提交后数据自动归档存储

### 数据与统计

- [x] **DATA-01**: 有权限的用户可查看表单所有提交数据，支持分页和筛选
- [x] **DATA-02**: 用户可查看单条提交的详细内容
- [x] **DATA-03**: 支持浏览器打印提交数据（类似纸质表格排版）
- [x] **DATA-04**: 支持导出提交数据为 PDF 文件
- [x] **DATA-05**: 基础统计：每个员工的分享次数和收集数量
