# Milestone v1.1: 自定义表单收集

**Status:** SHIPPED 2026-04-20
**Phases:** 7-9
**Total Plans:** 13

## Overview

将线下纸质信息登记表数字化 — 自定义模板、链接分享、外部免登录填写、数据归档查看打印、员工工作量统计

## Phases

### Phase 7: 模板管理 + 表单设计器

**Goal**: 管理员可创建、设计、发布表单模板，设计器支持拖拽排序和全部字段类型（含手写签名），模板修改自动版本化
**Depends on**: Phase 6 (v1.0 RBAC + 认证基础)
**Requirements**: TMPL-01, TMPL-02, TMPL-03, TMPL-04, TMPL-05, DSGN-01, DSGN-02, DSGN-03, DSGN-04, DSGN-05
**Plans**: 5 plans

Plans:
- [x] 07-01: Backend: Prisma FormTemplate model + CRUD/publish API + permission seeds
- [x] 07-02: Frontend: Template list page (QTable) + Pinia store + route registration
- [x] 07-03: Frontend: 3-panel form designer (palette + canvas + property editor)
- [x] 07-04: Frontend: SignatureField component + dependency install + sidebar nav
- [x] 07-05: Checkpoint: End-to-end human verification walkthrough (28/28 passed)

**Success Criteria** (all met):
1. 用户可创建模板（填写名称和描述），可编辑和删除自己的模板，操作受 RBAC 权限控制
2. 用户可在设计器中通过拖拽添加和排序字段，支持全部 7 种字段类型
3. 用户可配置每个字段的属性（必填、提示文字、选项列表），设计器右侧实时预览
4. 用户可发布/下线模板，下线后模板不可被分享填写
5. 修改已发布模板后 schema 版本自动递增

### Phase 8: 分享链接 + 公开填写

**Goal**: 员工可为已发布模板生成分享链接和二维码，外部人员通过链接免登录填写表单（含签名），提交数据自动归档
**Depends on**: Phase 7
**Requirements**: SHARE-01, SHARE-02, SHARE-03, SHARE-04, SHARE-05
**Plans**: 4 plans

Plans:
- [x] 08-01: 数据层：Prisma ShareLink + Submission 模型 + 依赖安装 + DB push
- [x] 08-02: 后端 API：分享链接创建端点 + 公开填写/提交 API
- [x] 08-03: 前端管理端：ShareDialog + 分享按钮 + 身份信息开关
- [x] 08-04: 公开填写页：FormFieldRenderer + PublicFillPage + 路由 + 端到端验证

**Success Criteria** (all met):
1. 用户可为已发布模板生成唯一分享链接，系统记录分享人和分享时间
2. 分享链接可生成二维码，扫码后直接打开填写页面
3. 外部人员通过浏览器打开分享链接，无需登录即可填写表单并提交
4. 模板可配置是否要求填写者提供身份信息
5. 填写者提交后数据自动归档存储，关联模板版本快照和分享记录

### Phase 9: 数据查看 + 打印 + 统计

**Goal**: 有权限的用户可查看、筛选、打印所有提交数据，并查看员工分享/收集工作量统计
**Depends on**: Phase 8
**Requirements**: DATA-01, DATA-02, DATA-03, DATA-04, DATA-05
**Plans**: 4 plans

Plans:
- [x] 09-01: 后端 API：权限种子 + 提交数据查询 + 员工统计聚合
- [x] 09-02: 前端基础层：npm 依赖安装 + submission store + 打印样式 + PDF 导出
- [x] 09-03: 前端页面：SubmissionPage 列表+详情抽屉+打印+PDF 导出+路由+入口
- [x] 09-04: 统计面板：FormStatsPanel 表格+图表 + Dashboard 嵌入

**Success Criteria** (all met):
1. 有权限的用户可查看某模板下所有提交数据列表，支持分页和按填写者/日期筛选
2. 用户可点击查看单条提交的完整详情（含签名图片和所有字段值）
3. 用户可通过浏览器打印提交数据，打印排版接近纸质表格效果
4. 用户可将提交数据导出为 PDF 文件保存
5. 用户可查看基础统计面板：每个员工的分享次数和收集数量

## Milestone Summary

**Key Decisions:**
- JSONB for form schema storage in PostgreSQL
- vue-draggable-plus for drag-drop form designer
- signature_pad for handwritten signatures
- nanoid for share link tokens (12-char, URL-safe)
- Browser window.print() + @media print CSS for printing (no server-side PDF)
- Public routes in separate Elysia group (no authGuard)
- Schema versioning — snapshot at submission time
- vue-chartjs Bar for stats visualization

**Issues Resolved:**
- Code review 修复 5 项安全/健壮性问题（WR-01~WR-05）
- PublicFillPage 独立 axios 实例避免 JWT 泄露
- 批量 PDF 导出上限 50 条防止内存溢出

**Technical Debt Incurred:**
- REQUIREMENTS.md traceability 表部分需求未同步勾选（功能已交付）
- 无服务端 PDF 生成（依赖 html2canvas 客户端渲染）
