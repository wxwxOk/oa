**变更 1 — onDelete 函数的 Dialog.create 对齐 Phase 3 风格**
将 onDelete 函数（约 line 124-130）从:
```typescript
function onDelete(r: any) {
  Dialog.create({ title: '确认删除', message: `删除角色 ${r.name}?`, cancel: true }).onOk(async () => {
    await api.delete(`/roles/${r.id}`);
    if (selected.value?.id === r.id) selected.value = null;
    await loadRoles();
  });
}
```
改为:
```typescript
function onDelete(r: any) {
  Dialog.create({
    title: '删除角色',
    message: `将永久删除角色 ${r.name}。此操作不可恢复。`,
    cancel: true,
    ok: { label: '确认删除', color: 'negative' },
  }).onOk(async () => {
    await api.delete(`/roles/${r.id}`);
    Notify.create({ type: 'positive', message: '已删除' });
    if (selected.value?.id === r.id) selected.value = null;
    await loadRoles();
  });
}
```
变化点：(1) title 改为 "删除角色"；(2) message 改为 "将永久删除角色 X。此操作不可恢复。"；(3) 新增 `ok: { label: '确认删除', color: 'negative' }`；(4) 删除成功后 Notify 提示 "已删除"。对齐 DepartmentPage.vue 的 onDelete 风格 (D-09)。
