## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | auth.route.ts login | mitigate | bcrypt.compareSync 验证密码，不返回具体错误（统一"用户名或密码错误"） |
| T-02-02 | Spoofing | auth.route.ts refresh | mitigate | refreshJwt.verify 验证签名 + payload.type === 'refresh' 防止 access token 冒充 |
| T-02-03 | Tampering | Prisma queries | mitigate | Prisma 参数化查询，天然防 SQL 注入 |
| T-02-04 | Information Disclosure | JWT secret | mitigate | 启动时校验 JWT_SECRET >= 32 字符，拒绝弱 secret |
| T-02-05 | Elevation of Privilege | auth.ts guard | mitigate | accessJwt.verify 验证 token + type === 'access' 校验 + 用户状态检查（DISABLED 拒绝） |
| T-02-06 | Information Disclosure | localStorage | accept | 内部 OA 系统，localStorage 存储 token 风险可接受，依赖 CSP 防 XSS |
</threat_model>
