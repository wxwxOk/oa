    **Per D-01: 后端 Dockerfile 真·多阶段构建（保留源码模式）**

    重写 `backend/Dockerfile`：

    Stage 1 — builder:
    ```dockerfile
    FROM oven/bun:1.3-alpine AS builder
    WORKDIR /app
    COPY package.json bun.lock ./
    COPY prisma ./prisma
    RUN bun install --frozen-lockfile
    RUN bunx prisma generate
    ```

    Stage 2 — runner:
    ```dockerfile
    FROM oven/bun:1.3-alpine
    WORKDIR /app
    RUN apk add --no-cache curl openssl
    COPY package.json bun.lock ./
    RUN bun install --frozen-lockfile --production
    COPY --from=builder /app/node_modules/.prisma ./node_modules/.prisma
    COPY --from=builder /app/node_modules/@prisma ./node_modules/@prisma
    COPY src ./src
    COPY prisma ./prisma
    ENV NODE_ENV=production
    EXPOSE 3000
    HEALTHCHECK --interval=30s --timeout=5s --start-period=10s --retries=3 \
      CMD curl -f http://localhost:3000/health || exit 1
    CMD ["sh", "-c", "bunx prisma migrate deploy && bun run prisma/seed.ts && bun run src/index.ts"]
    ```

    关键点：runner 阶段先 `bun install --production`（仅生产依赖如 elysia/bcryptjs），再从 builder 覆盖 .prisma 和 @prisma 目录（prisma generate 产物）。不复制整个 /app。Per D-03 添加 HEALTHCHECK 使用 curl。
