### Surface C: Stats Panel (Dashboard embed)

| Element | Description |
|---------|-------------|

## Interaction Contract

### Submission List Flow

1. User clicks "查看数据" on TemplatePage row → navigates to `/templates/:id/submissions`
2. Page loads with default pagination (page=1, size=20), fetches submission list
3. Loading state: QTable built-in `:loading="true"` skeleton rows
4. Empty state: EmptyState component (icon: "inbox", title: "暂无提交数据", description: "该模板还没有收到任何提交")
5. Filter: user fills filter fields → clicks "查询" → re-fetches with filters
6. Reset: clears all filters → re-fetches without filters
7. Pagination: QTable server-side pagination events trigger re-fetch

### Detail Drawer Flow

1. User clicks "查看" icon in row → drawer opens from right
2. Drawer fetches full submission detail (if not already in list data)
3. If schemaVersion matches template current version → render with field labels from schema
4. If schemaVersion mismatch → render key-value pairs + show warning banner
5. Signature field: render as `<img>` with base64 data URI

### Print Flow

1. User clicks "打印" button in drawer (or row action)
2. System calls `window.print()`
3. @media print CSS activates:
   - Hides all UI except `#print-area`
   - `#print-area` becomes `position: fixed; top: 0; left: 0; width: 100%`
   - Table renders with borders, proper font sizes
   - Signature image renders at bottom
4. Browser native print dialog appears
5. User prints or cancels — no app state change needed

### PDF Export Flow (Single)

1. User clicks "导出 PDF" in drawer
2. Button shows loading state
3. `html2canvas(printArea, { scale: 2, backgroundColor: '#ffffff' })` captures DOM
4. `jsPDF` creates A4 PDF with 15mm margins
5. If content exceeds one page → automatic page splitting
6. `pdf.save('{模板名称}_{提交时间}.pdf')`
7. Button returns to normal state

### PDF Export Flow (Batch)

1. User selects rows via checkboxes in QTable
2. Batch action bar appears at bottom: "已选 {n} 条" + "批量导出 PDF" button
3. Click triggers progress dialog (persistent)
4. System processes each submission sequentially:
   - Renders detail DOM off-screen (hidden div)
   - html2canvas captures → adds page to single PDF
   - Updates progress: `{current}/{total}`
5. Maximum 50 items per batch (if > 50 selected, show warning and truncate)
6. On complete: `pdf.save('{模板名称}_批量导出.pdf')` + close dialog
7. Cancel button: stops processing, saves what's done so far (or discards — user choice)

### Stats Panel Flow

1. Dashboard loads → if user has `form:stats:view` permission, FormStatsPanel renders
2. Default period: "本月"
3. Fetches GET `/api/v1/form-stats?dateFrom=...&dateTo=...`
4. Loading state: QSkeleton for table + chart area
5. Data renders in both table and chart simultaneously
6. User switches period → re-fetches with new date range
7. Custom range: QDate range picker → apply → re-fetch
