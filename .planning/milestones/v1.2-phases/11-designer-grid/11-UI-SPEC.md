# Phase 11 — UI Design Contract

> Visual and interaction contract for designer-grid phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Vue 3 + Quasar Framework) |
| Preset | not applicable |
| Component library | Quasar (QBtn, QIcon, QSlider, QInput, QToggle, QDialog) |
| Icon library | Material Icons (via Quasar) |
| Font | System stack: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif |
| Drag library | vue-draggable-plus (SortableJS wrapper) |
| Layout engine | CSS Grid (12-column: `repeat(12, 1fr)`) |
| State management | Pinia (useTemplateStore) |

---

## Spacing Scale

Declared values (multiples of 4, consistent with existing codebase):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Row gap between field cards, inline icon gaps |
| sm | 8px | Grid column gap, palette item padding, compact spacing |
| md | 16px | Canvas padding, grid row gap, section padding, PropertyEditor padding |
| lg | 24px | Not used in this phase |
| xl | 32px | Not used in this phase |

Exceptions:
- Drag handle hit area: 24x full-row-height (wider than visual icon for touch target)
- Resize handle hit area: 8x8px visual, 16x16px clickable (centered on corner)
- Row gap between grid rows: 8px (matches existing GridFormRenderer `gap: 8px 16px`)

## Interaction Contract

### Canvas Layout Structure

```
┌─────────────────────────────────────────────────┐
│ DesignerCanvas (--oa-bg background)             │
│                                                 │
│  ┌─ Row 0 ─────────────────────────────────┐   │
│  │ ⠿ │ [Field A: span 6] │ [Field B: span 6] │ │
│  └──────────────────────────────────────────┘   │
│  ┌─ Row 1 ─────────────────────────────────┐   │
│  │ ⠿ │ [Field C: span 12]                    │ │
│  └──────────────────────────────────────────┘   │
│  ┌─ Row 2 ─────────────────────────────────┐   │
│  │ ⠿ │ [Field D: span 4] │ ┊ empty (8 col) ┊│ │
│  └──────────────────────────────────────────┘   │
│  ┊ ─ ─ ─ ─ ─ Drop zone (new row) ─ ─ ─ ─ ─ ┊ │
│                                                 │
└─────────────────────────────────────────────────┘
```

### Field Card States

| State | Border | Background | Shadow | Extras |
|-------|--------|------------|--------|--------|
| Default | 1px solid --oa-border | --oa-surface | none | Drag handle (left), delete btn (top-right) |
| Hover | 1px solid --q-primary | --oa-surface | none | Same as default |
| Selected | 2px solid --q-primary | --oa-surface | 0 0 0 2px rgba(--q-primary, 0.15) | + 4 corner resize handles |
| Dragging | 1px solid --oa-border | --oa-surface | 0 4px 12px rgba(0,0,0,0.1) | opacity: 0.8, cursor: grabbing |
| Ghost (SortableJS) | 1px dashed --q-primary | transparent | none | opacity: 0.4 |

### Field Card Content (D-03: WYSIWYG)

Each field card renders the actual FieldRenderer in `mode="designer"` (disabled preview). Layout:

```
┌──────────────────────────────────────┐
│ ⠿ │ FieldRenderer(mode=designer)  │ ✕ │
│   │ (disabled input preview)      │   │
└──────────────────────────────────────┘
```

- Drag handle: `drag_indicator` icon, 16px, grey-5, left side, `cursor: grab`
- Delete button: QBtn flat dense round, icon `close`, size `xs`, top-right corner, visible on hover or selected
- Field content: FieldRenderer fills remaining space via `flex: 1`

### Resize Handles (D-04, D-09, D-10)

Visible only on selected field. 4 corner dots, but only right-side handles are functional for width resize.

| Property | Value |
|----------|-------|
| Visual size | 8px diameter circle |
| Hit area | 16px diameter (centered) |
| Color | --q-primary (filled circle) |
| Background | --oa-surface (white ring around dot) |
| Cursor | `col-resize` (right handles), `default` (left handles, non-functional) |
| Snap | 1 column unit (grid-column width) |
| Min span | 1 column |
| Max span | remaining space in row + current field span |
| Feedback | Tooltip showing "{N} / 12 列" during drag |

### Drop Zones (D-02, D-05)

| Zone | Visual | Trigger |
|------|--------|---------|
| Row remainder (empty columns) | Dashed border, --oa-border color, border-radius 6px | Visible when row colSpan sum < 12 |
| Row remainder (drag hover) | Dashed border changes to --q-primary, background --oa-hover | When dragging field over remainder area |
| Between rows (insert line) | 2px solid --q-primary horizontal line, full canvas width | When dragging between existing rows |
| Bottom drop zone | Dashed border area, 64px height, "拖入字段创建新行" text | Always visible at canvas bottom |
| Bottom drop zone (drag hover) | Border --q-primary, background --oa-hover | When dragging over bottom zone |

### Row Drag (D-06)

| Property | Value |
|----------|-------|
| Handle | `drag_indicator` icon, 16px, left side of each row |
| Handle visibility | Always visible (opacity 0.5, hover opacity 1.0) |
| Drag direction | Vertical only |
| Animation | 150ms (SortableJS default) |
| Delete row button | `delete_outline` icon, visible on row hover, right side |

### Row Auto-Cleanup (D-12)

When last field removed from row (delete or drag-out), row is immediately removed from schema. No animation needed — SortableJS handles DOM transition.

### Overflow Protection (D-08)

When field drop would cause row colSpan sum > 12:
1. Auto-compress new field colSpan to remaining space (minimum 1)
2. If remaining space = 0, reject drop (SortableJS `onMove` returns false)
3. No toast/notification needed — the visual drop zone absence communicates this

### PropertyEditor Sync (D-09)

colSpan slider in PropertyEditor (already exists: QSlider min=1 max=12 step=1) syncs bidirectionally with canvas resize handles. Slider max dynamically adjusts to: `remaining row space + current field colSpan`.

## Accessibility

| Concern | Implementation |
|---------|---------------|
| Focus visible | Existing `.q-field--outlined` focus ring (2px --oa-focus-ring) applies to FieldRenderer inputs |
| Keyboard field selection | Tab through field cards, Enter/Space to select |
| Keyboard delete | Delete/Backspace key removes selected field |
| Drag handle aria | `aria-label="拖拽排序"` on drag handle elements |
| Screen reader row context | `aria-label="第 {N} 行, {M} 个字段"` on each row |
| Resize via keyboard | Arrow keys adjust colSpan when field is selected (Left -1, Right +1) |
| Color contrast | All text meets WCAG AA: --oa-text-primary on --oa-surface = #0F172A on #FFFFFF (21:1) |
