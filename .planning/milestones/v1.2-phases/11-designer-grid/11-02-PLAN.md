    Complete rewrite of DesignerCanvas.vue. The component becomes a two-layer architecture:
    1. CSS Grid rendering layer (replicates GridFormRenderer's `.grid-row` pattern)
    2. Overlay interaction layer (drag handles, selection, resize handles, drop zones)

    **Architecture (all inline in single SFC — no sub-components):**

    The component renders rows from `schema.items` (filtered to `type === 'row'`). Each row is a flex container with: row drag handle (left) + grid fields container (center) + row delete button (right, hover-visible).

    **Template structure:**

    ```
    <div class="grid-canvas" @click.self="store.selectField(null)">
      <div ref="rowsRef" class="canvas-rows">
        <!-- For each row in schema.items where type === 'row' -->
        <div class="grid-canvas-row" v-for="(row, rowIdx) in rows" :key="rowIdx">
          <!-- Row drag handle (D-06) -->
          <div class="row-handle row-drag-handle">
            <q-icon name="drag_indicator" size="16px" color="grey-5" />
          </div>

          <!-- Fields grid container (SortableJS target per row) -->
          <div :ref="el => setRowFieldsRef(rowIdx, el)" class="row-fields-grid">
            <!-- Each field card -->
            <div v-for="field in row.fields" :key="field.id"
                 class="grid-canvas-field"
                 :class="{ 'is-selected': store.selectedFieldId === field.id }"
                 :style="{ gridColumn: `span ${field.colSpan}` }"
                 @click.stop="store.selectField(field.id)">
              <!-- Field drag handle -->
              <div class="field-drag-handle">
                <q-icon name="drag_indicator" size="14px" color="grey-5" />
              </div>
              <!-- FieldRenderer preview (D-03, D-04 WYSIWYG) -->
              <div class="field-preview">
                <FieldRenderer :field="field" mode="designer" />
              </div>
              <!-- Delete button (D-13) -->
              <q-btn flat dense round icon="close" size="xs" class="field-delete-btn"
                     @click.stop="removeField(field.id)" />
              <!-- Resize handle (D-04, D-09, D-10 — only when selected) -->
              <div v-if="store.selectedFieldId === field.id"
                   class="resize-handle resize-handle-right"
                   @pointerdown="startResize($event, field, rowIdx)" />
            </div>

            <!-- Row remainder placeholder (D-02) -->
            <div v-if="remainingCols(row.fields) > 0"
                 class="row-remainder drop-placeholder"
                 :style="{ gridColumn: `span ${remainingCols(row.fields)}` }">
            </div>
          </div>

          <!-- Row delete button (D-11, hover) -->
          <q-btn flat dense round icon="delete_outline" size="xs"
                 class="row-delete-btn" @click="deleteRow(rowIdx)" />
        </div>
      </div>

      <!-- Bottom drop zone for new rows (D-05) -->
      <div ref="bottomDropRef" class="canvas-drop-zone">
        <span>拖入字段创建新行</span>
      </div>

      <!-- Empty state (when no rows) -->
      <div v-if="rows.length === 0 && !hasNonRowItems" class="empty-state">
        <span>从左侧拖入字段开始设计表单</span>
      </div>
    </div>
    ```

    **Script setup logic:**

    1. **Schema access:** Use `ensureSchema()` pattern (same as current). Extract `rows` as computed getter filtering `schema.items` to `type === 'row'` only.

    2. **Row-level drag (D-06):** Use `useDraggable(rowsRef, rowList, {...})` with:
       - `group: { name: 'rows', pull: false, put: false }`
       - `handle: '.row-drag-handle'`
       - `animation: 150`
       - `ghostClass: 'row-ghost'`
       - The `rowList` computed get/set must update `schema.items` preserving non-row items in their positions.

    3. **Field-level drag per row:** For each row, call `useDraggable` on the row's fields ref with:
       - `group: { name: 'fields', pull: true, put: true }`
       - `handle: '.field-drag-handle'`
       - `animation: 150`
       - `emptyInsertThreshold: 20`
       - `fallbackOnBody: true`
       - `swapThreshold: 0.65`
       - `filter: '.row-remainder'` (exclude placeholder from sorting, per Research Open Question 1)
       - `onAdd` callback: call `compressColSpan(field, row.fields)` per D-08
       - `onRemove` callback: if `row.fields.length === 0`, remove row from schema (D-12)

       **IMPORTANT:** Since rows are dynamic (added/removed), use a `watchEffect` or `onUpdated` to re-initialize SortableJS instances when row count changes. Alternatively, use `VueDraggable` component (from vue-draggable-plus) instead of `useDraggable` composable for field-level drag, as the component handles lifecycle automatically.

       **Recommended approach:** Use `<VueDraggable>` component for field-level drag (it handles v-for reactivity), and `useDraggable` composable for row-level drag (single container).

       ```typescript
       import { VueDraggable } from 'vue-draggable-plus';
       ```

    4. **Bottom drop zone (D-05):** Use a separate `useDraggable` on `bottomDropRef` with:
       - `group: { name: 'fields', pull: false, put: true }`
       - `onAdd`: create new row with the dropped field, call `compressColSpan`

    5. **Resize handling (D-09, D-10):** `startResize(e, field, rowIdx)` function:
       - Get the row's fields grid element
       - Calculate `maxColSpan = remainingCols(row.fields) + field.colSpan`
       - Create refs and call `useColResize({ field: ref(field), rowEl: ref(gridEl), maxColSpan: ref(max) })`
       - Or inline the pointer logic directly (simpler for single-use):
         ```typescript
         function startResize(e: PointerEvent, field: SchemaField, rowIdx: number) {
           e.preventDefault();
           e.stopPropagation();
           const el = rowFieldsRefs[rowIdx];
           if (!el) return;
           const colWidth = el.clientWidth / 12;
           const startX = e.clientX;
           const startSpan = field.colSpan;
           const max = remainingCols(rows.value[rowIdx].fields) + field.colSpan;
           resizingFieldId.value = field.id;

           function onMove(ev: PointerEvent) {
             const delta = Math.round((ev.clientX - startX) / colWidth);
             field.colSpan = Math.max(1, Math.min(max, startSpan + delta));
           }
           function onUp() {
             resizingFieldId.value = null;
             document.removeEventListener('pointermove', onMove);
             document.removeEventListener('pointerup', onUp);
           }
           document.addEventListener('pointermove', onMove);
           document.addEventListener('pointerup', onUp);
         }
         ```

    6. **Field removal (D-13):** `removeField(id)` — find field in rows, splice it out, if row becomes empty splice row out (D-12). Clear selection if removed field was selected.

    7. **Row deletion (D-11):** `deleteRow(rowIdx)` — splice row from schema.items. Clear selection if any field in that row was selected.

    8. **Keyboard support (from UI-SPEC accessibility):**
       - Arrow Left/Right on selected field: adjust colSpan -1/+1 (clamped)
       - Delete/Backspace on selected field: remove field
