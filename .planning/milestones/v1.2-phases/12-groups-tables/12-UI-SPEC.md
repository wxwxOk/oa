## Interaction Contracts

### Group Interactions (Designer)

| Interaction | Behavior |
|-------------|----------|
| Drag from palette | Clone creates `{ type: 'group', id: UUID, title: '分组标题', rows: [] }`, inserts into `items[]` |
| Click group header | Selects group, PropertyEditor shows group branch |
| Click canvas background | Deselects (`store.selectField(null)`) |
| Drag field into group | Field enters group's `DesignerRowEditor`, creates new row if needed. Cross-boundary drag via `group: { name: 'fields' }` |
| Drag field out of group | Field leaves group row. Empty row auto-cleaned. Empty group persists (user can delete manually) |
| Drag group handle | Reorders group position in `items[]` via `.item-drag-handle` |
| Delete group | Removes group AND all contained rows/fields from `items[]`. No confirmation (D-08) |
| Keyboard Delete/Backspace | If group selected, delete group |

### Dynamic Table Interactions (Designer)

| Interaction | Behavior |
|-------------|----------|
| Drag from palette | Clone creates table with 2 default text columns, inserts into `items[]` |
| Click table card | Selects table, PropertyEditor shows table branch |
| Add column | Appends `{ key: UUID, label: '列 N', type: 'text' }` to columns array |
| Delete column | Removes column from array. Minimum 1 column enforced |
| Reorder columns | Drag via `.col-drag-handle` within PropertyEditor column list |
| Change column type | `q-select` updates `column.type`. If switching away from radio/checkbox, clear options |
| Delete table | Removes from `items[]`. No confirmation (consistent with D-08) |

### Dynamic Table Interactions (Fill)

| Interaction | Behavior |
|-------------|----------|
| Add row | Click "添加行" appends empty row object to array, emits update |
| Delete row | Click row delete icon removes row. If last row deleted, auto-create 1 empty row |
| Cell edit | Standard `FieldRenderer` fill mode input. Updates `formData[tableId][rowIdx][colKey]` |
| Initial load | 1 empty row if no existing data (D-14) |

### Item-Level Drag Sorting (D-04)

| Property | Value |
|----------|-------|
| Handle class | `.item-drag-handle` (distinct from `.row-drag-handle` and `.field-drag-handle`) |
| Scope | Top-level `items[]` array: rows, groups, and dynamic tables |
| SortableJS group | `{ name: 'items', pull: false, put: false }` (no cross-container) |
| Animation | 150ms |
| Ghost class | `item-ghost` (opacity 0.4) |
