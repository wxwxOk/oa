**DynamicTableFill.vue** — Fill mode with add/remove rows (D-13, D-14, D-15)

Props:
```typescript
import type { DynamicTableColumnType } from 'src/types/schema';
interface Column {
  key: string; label: string; type: DynamicTableColumnType;
  width?: number; options?: string[];
}
const props = defineProps<{
  label: string; columns: Column[];
  modelValue?: Record&lt;string, any&gt;[];
}>();
const emit = defineEmits<{
  'update:modelValue': [value: Record&lt;string, any&gt;[]];
}>();
```

Script:
- `rows = ref([])` local state
- `createEmptyRow()`: iterate columns, set `col.type === 'checkbox' ? [] : ''` per key
- `onMounted`: if modelValue has data, copy it; else init with 1 empty row (D-14)
- `addRow()`: push createEmptyRow(), emitUpdate
- `removeRow(idx)`: splice, if length===0 push createEmptyRow(), emitUpdate
- `updateCell(rowIdx, colKey, value)`: set rows[rowIdx][colKey], emitUpdate
- `emitUpdate()`: emit('update:modelValue', rows.map(r => ({...r})))

Template — native HTML table per D-16 and UI-SPEC section 6:
- q-card flat bordered wrapper with `.table-label` header (16px/600, padding 16px 16px 8px, border-bottom)
- `<table>` width 100%, border-collapse collapse
- `<thead>` with column labels (14px/600, padding 8px, border-bottom 2px, bg var(--oa-bg)) + 40px action column
- `<tbody>` rows with transition background 150ms, hover var(--oa-hover)
- Each cell: q-input (text/phone), q-input+q-date (date), q-select (radio), q-select multiple (checkbox)
- Action cell: q-btn delete_outline, opacity 0 default, opacity 1 on row hover
- Below table: q-btn flat "添加行" icon add, color primary, full width, border-top

Styles: `.table-label`, `.fill-table`, `.fill-th`, `.fill-th-action`, `.fill-row`, `.fill-td`, `.fill-td-action`, `.row-delete-icon` (opacity 0, hover 1), `.add-row-btn`
