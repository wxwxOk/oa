**文件结构（从上到下）：**

**1. Imports + 类型定义 + 常量：**
```typescript
import html2canvas from 'html2canvas';
import { jsPDF } from 'jspdf';

export interface BreakCandidate {
  y: number;
  type: 'row' | 'group-start' | 'group-row' | 'table-start' | 'table-row';
  isTableInternal: boolean;
  tableHeaderRect?: { y: number; height: number };
}

export interface PageSlice {
  startY: number;
  endY: number;
  needsTableHeader: boolean;
  tableHeaderRect?: { y: number; height: number };
}

const A4_HEIGHT = 297;
const MARGIN = 15;
const HEADER_HEIGHT = 10;
const FOOTER_HEIGHT = 10;
const CONTENT_TOP = MARGIN + HEADER_HEIGHT;       // 25mm
const CONTENT_BOTTOM = A4_HEIGHT - MARGIN - FOOTER_HEIGHT; // 272mm
const MAX_CONTENT_HEIGHT = CONTENT_BOTTOM - CONTENT_TOP;   // 247mm
const HEADER_Y = 8;
const FOOTER_Y = A4_HEIGHT - 8;
```

**2. collectBreakpoints — DOM 坐标扫描：**
扫描 container 内所有 `[data-break]` 元素，用 `getBoundingClientRect()` 收集 Y 坐标。对 `data-break="table-row"` 的元素，额外查找最近的 `[data-thead]` 获取表头坐标。返回按 y 排序的 BreakCandidate[]。

**3. findBestBreak — 切点查找：**
从已排序的 candidates 中找到 y <= pageBottom 的最后一个候选。candidates 为空或没有 <= pageBottom 的候选时返回 null。

**4. computePageSlices — 页面切片计算：**
循环处理 totalHeight，每次找 pageBottom 范围内的最佳切点。找到则在切点处分割，找不到则强制按 pageContentHeight 切并 `console.warn('[PDF] 无法找到安全切点，强制分页')`。切点在动态表格内部时标记 `needsTableHeader: true`。

**5. injectHeaderFooter — 页眉页脚注入（per D-08/D-09/D-10/D-11）：**
遍历所有页面，每页：
- 页眉：`pdf.text(formTitle, pageWidth/2, 8, { align: 'center' })` — 10pt, #666
- 页脚左：`pdf.text(submitTime, 15, 289)` — 10pt, #666
- 页脚右：`pdf.text('N / M', pageWidth-15, 289, { align: 'right' })` — 10pt, #666

**6. renderPageSlice — 内部辅助函数：**
处理单个 PageSlice 的 canvas 切片渲染。如果 needsTableHeader，先从原始 canvas 裁剪 thead 区域绘制到新页顶部，再绘制内容切片。

**7. exportToPdf 重写（签名不变）：**
1. 从 element 的 data-form-title / data-submit-time 读取元数据
2. collectBreakpoints(element) 收集切点
3. html2canvas(element, { scale: 2, useCORS: true, logging: false, backgroundColor: '#ffffff' })
4. computePageSlices 计算切片
5. 单页直接 addImage，多页按切片 renderPageSlice
6. injectHeaderFooter 注入页眉页脚
7. pdf.save(filename)

入口处添加 canvas 安全阈值检查：elementHeight * scale > 16000 时 console.warn。

**8. exportBatchToPdf 重写（签名不变）：**
与 exportToPdf 类似但 scale=1.5, quality=0.9。每个提交独立收集 breakpoints 和计算 slices。保留 cancelRef 和 onProgress。页眉页脚在所有提交渲染完毕后统一注入。

具体代码见 RESEARCH.md Pattern 2/3/4 和 PATTERNS.md 中的代码示例。
