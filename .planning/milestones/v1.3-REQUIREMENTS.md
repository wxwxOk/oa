# v1.3 Requirements: 到访信息管理

## 到访记录

- [x] **VISIT-01**: 有权限用户可新建到访记录，填写姓名、年龄、学历、性别、渠道商、咨询师、接待状态、接待人、接待日期等基础信息
- [x] **VISIT-02**: 有权限用户可编辑到访记录的全部字段，含咨询后状态、状态类别、状态说明、试听课后状态、解决方案、试听课时间
- [x] **VISIT-03**: 有权限用户可删除误录的到访记录
- [x] **VISIT-04**: 有权限用户可查看单条到访记录详情，长文本字段完整展示

## 查询筛选

- [x] **QUERY-01**: 有权限用户可分页查看到访列表，支持按姓名关键词搜索
- [x] **QUERY-02**: 有权限用户可按渠道商、咨询师、接待人、接待状态、咨询后状态、状态类别、接待日期区间筛选
- [x] **QUERY-03**: 筛选下拉项从现有到访记录中去重提取，不需要单独维护字典
- [x] **QUERY-04**: 列表在 PC 端使用表格，在移动端使用卡片，长文本只展示摘要

## Excel 导入

- [x] **IMPORT-01**: 有权限用户可导入 `.xlsx`，系统识别第 1 行标题、第 2 行 15 列表头、第 3 行起数据
- [x] **IMPORT-02**: 导入前用户可预览解析结果，看到有效行、无效行和错误原因
- [x] **IMPORT-03**: 系统按「姓名 + 接待日期 + 咨询师」提示潜在重复，但不自动跳过或合并
- [x] **IMPORT-04**: 用户确认后系统批量创建有效到访记录，并返回导入数量

## 统计分析

- [x] **STAT-01**: 有权限用户可查看按渠道商汇总的到访数量、意向数量、签约类数量和转化概览
- [x] **STAT-02**: 有权限用户可查看按咨询师、接待人汇总的到访/意向/签约类数量
- [x] **STAT-03**: 有权限用户可查看咨询后状态、状态类别、试听课后状态的分布统计
- [x] **STAT-04**: 统计支持按接待日期区间筛选

## 权限集成

- [x] **PERM-01**: 到访模块拥有独立菜单和 `visit:list/create/update/delete/import/stats` 权限码
- [x] **PERM-02**: 前端按钮显隐和后端端点都按对应权限控制
