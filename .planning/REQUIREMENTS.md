# Requirements: v1.4 报销管理

**Defined:** 2026-05-02
**Milestone:** v1.4
**Scope:** 固定业务模块，不复用自定义表单 JSONB 作为主数据模型。

## v1.4 Requirements

### 报销申请

- [ ] **REIM-01**: 员工可新建报销申请，填写报销标题、报销类别、发生日期、金额、事由、收款信息和备注。
- [ ] **REIM-02**: 报销金额必须大于 0；标题、类别、发生日期、金额、事由为必填；提交后员工不可直接修改已进入审核流的核心字段。
- [ ] **REIM-03**: 员工可查看自己的报销申请列表和详情，列表支持按状态、类别、发生日期区间和关键词筛选。
- [ ] **REIM-04**: 有权限用户可查看全部报销申请；普通员工只能查看自己提交的申请。

### 发票附件

- [ ] **INV-01**: 员工提交申请时可上传多张发票或相关凭证附件，支持图片和 PDF。
- [ ] **INV-02**: 附件需记录原始文件名、文件类型、文件大小、上传人和上传时间，并与报销申请绑定。
- [ ] **INV-03**: 申请详情页可预览图片附件、下载 PDF/原始附件；附件访问必须经过登录和权限校验。
- [ ] **INV-04**: 本期不做 OCR、发票查验、自动验重或自动金额识别，发票信息以人工填写为准。

### 两级审核与签字

- [ ] **APPROVAL-01**: 报销申请提交后进入部门初审，部门审核人员可通过或驳回，并填写审核意见。
- [ ] **APPROVAL-02**: 部门初审通过后进入财务复核，财务审核人员可通过或驳回，并填写审核意见。
- [ ] **APPROVAL-03**: 部门初审和财务复核通过时均需使用 Canvas 手写签名，保存签名图片、审核人、审核时间和审核动作。
- [ ] **APPROVAL-04**: 驳回后申请状态变为已驳回，员工可查看驳回节点、驳回人、驳回时间和驳回原因。
- [ ] **APPROVAL-05**: 申请详情页展示完整审核轨迹，包含提交、部门初审、财务复核、签字和驳回记录。

### 导出

- [ ] **EXPORT-01**: 有权限用户可按当前筛选条件导出报销列表 Excel。
- [ ] **EXPORT-02**: 导出内容包含申请基础信息、附件数量、当前状态、部门审核结果、财务审核结果和最终通过时间。
- [ ] **EXPORT-03**: 本期只做明细导出，不做统计报表、图表看板或财务支付流程。

### 权限与导航

- [ ] **PERM-01**: 新增报销管理菜单和权限码，至少覆盖申请查看、申请创建、部门审核、财务审核、附件访问和导出。
- [ ] **PERM-02**: 前后端均使用 RBAC 控制按钮、页面入口和 API 访问；禁止仅依赖前端隐藏按钮。
- [ ] **PERM-03**: 报销模块沿用现有组织架构、用户和角色体系，不新增独立账号体系。

### 响应式与质量

- [ ] **UX-01**: PC 端提供表格列表、筛选区、详情抽屉/弹窗和审核操作；移动端提供卡片列表和可用的提交/审核体验。
- [ ] **UX-02**: 上传、提交、审核、签字和导出操作需要明确的成功/失败反馈。
- [ ] **NFR-01**: 文件上传限制类型和大小，后端必须校验并返回清晰错误信息。
- [ ] **NFR-02**: 列表接口保持分页，常用筛选字段建立索引，避免一次性返回全部报销记录。

## Out of Scope

- OCR 识别、发票真伪查验、自动验重、自动匹配金额。
- 预算控制、付款打款、会计凭证、财务系统对接。
- 复杂工作流：会签、并行审批、按金额动态分支、委托、超时升级。
- 统计看板和图表分析。

## UAT Checklist

| ID | 场景 | 预期 |
|---|---|---|
| UAT-1 | 员工填写报销信息并上传图片/PDF 发票后提交 | 申请进入部门初审，详情可查看附件 |
| UAT-2 | 部门审核人员手写签名并通过 | 申请进入财务复核，审核轨迹记录签字 |
| UAT-3 | 财务审核人员手写签名并通过 | 申请状态变为已通过，记录最终通过时间 |
| UAT-4 | 任一审核节点驳回并填写原因 | 员工可在详情看到驳回原因和节点 |
| UAT-5 | 普通员工尝试访问他人附件或审核接口 | 后端拒绝访问 |
| UAT-6 | 财务按状态/日期筛选并导出 Excel | 导出文件只包含当前筛选结果 |
