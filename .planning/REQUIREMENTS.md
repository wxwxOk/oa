# Requirements: v1.5 工作记录管理

**Defined:** 2026-05-03
**Milestone:** v1.5
**Scope:** 固定业务模块，不复用自定义表单 JSONB 作为主数据模型。
**Core Value:** 中小企业能用自定义表单快速上线可追踪、可审批、可归档的内部业务流程，并能通过固定业务模块沉淀高频台账数据。

## v1.5 Requirements

### 数据模型与周期

- [ ] **WRPT-01**: 系统新增固定 `WorkReport` 数据模型，统一承载日报、周报、月报。
- [ ] **WRPT-02**: 工作记录必须保存 `periodType`、`periodStart`、`periodEnd`，并由后端统一计算/校验周期边界。
- [ ] **WRPT-03**: 同一员工、同一周期类型、同一周期只能保留一条工作记录，避免重复汇总。
- [ ] **WRPT-04**: 工作记录保存提交人姓名、部门 ID 和部门名称快照，历史记录不因组织架构调整而失真。

### 固定模板与填报

- [ ] **FILL-01**: 员工可创建日报、周报、月报草稿。
- [ ] **FILL-02**: 固定模板字段覆盖完成事项、下一周期计划、问题风险、需要协助和备注。
- [ ] **FILL-03**: 员工可编辑自己的草稿并正式提交；提交后记录进入可汇总状态。
- [ ] **FILL-04**: 已提交记录默认不可直接修改，避免汇总口径被静默改变。
- [ ] **FILL-05**: “我的工作记录”支持按周期类型、状态、日期范围和关键词筛选，PC/Mobile 均可查看详情。

### 可见性与权限

- [ ] **VIS-01**: 普通员工只能查看和操作自己的工作记录。
- [ ] **VIS-02**: 具备部门查看权限的用户只能查看本部门员工工作记录和汇总。
- [ ] **VIS-03**: 具备全部查看权限的管理员可查看全公司工作记录和汇总。
- [ ] **VIS-04**: 前端菜单、按钮、路由和后端 API 均接入独立工作记录 RBAC 权限码，禁止只依赖前端隐藏。

### 部门汇总

- [ ] **SUMM-01**: 主管/管理员可按部门、人员、周期类型和日期范围查询提交情况。
- [ ] **SUMM-02**: 汇总结果展示应提交人数、已提交人数、未提交人数和提交率。
- [ ] **SUMM-03**: 汇总页可查看已提交记录摘要，并能定位到符合权限范围的记录详情。
- [ ] **SUMM-04**: 未提交人员清单从当前用户/部门数据计算，不新增提醒或待办表。

### Excel 导出

- [ ] **EXPT-01**: 授权用户可按当前筛选条件导出工作记录明细 Excel。
- [ ] **EXPT-02**: 导出文件至少包含明细 sheet 和汇总 sheet，汇总口径与页面一致。
- [ ] **EXPT-03**: 导出接口复用后端权限和可见性边界，并处理 Excel 公式注入风险和导出行数上限。

### 响应式与质量

- [ ] **UX-01**: PC 端提供筛选区、表格列表、表单编辑和详情查看体验。
- [ ] **UX-02**: 移动端提供卡片列表和可用的日报/周报/月报填写体验。
- [ ] **NFR-01**: 列表和汇总接口保持分页/限制返回量，常用筛选字段建立索引。
- [ ] **NFR-02**: 周期、必填字段、权限拒绝和重复提交错误必须返回清晰提示。

## v2 Requirements

### 协作与提醒

- **REM-01**: 支持日报/周报/月报截止时间和未提交提醒。
- **REM-02**: 支持主管手动催办未提交人员。
- **COMM-01**: 支持主管评论、退回修改和已读确认。

### 管理增强

- **STAT-01**: 支持趋势图、关键词统计和跨月对比。
- **TMPL-01**: 支持按部门或岗位配置不同工作记录模板。
- **PERF-01**: 支持与 OKR/KPI 或绩效评分关联。

### 集成与智能化

- **TASK-01**: 支持项目任务、工时或看板系统联动。
- **AI-01**: 支持 AI 自动摘要、风险识别和关键词分类。
- **INTG-01**: 支持钉钉、飞书、企业微信等第三方平台集成。

## Out of Scope

| Feature | Reason |
|---------|--------|
| 提醒推送、催办、截止时间 | 需要通知/调度体系，v1.5 先验证填报与汇总闭环 |
| 主管评论、退回修改、已读确认 | 会增加协作状态机，后续再做 |
| 评分、点赞、绩效、OKR/KPI | 属于绩效管理，不是轻量工作记录本体 |
| 项目工时、任务管理、甘特/看板 | 容易演变为项目管理系统，当前只做报表式记录 |
| AI 自动总结、关键词分类、风险分析 | 需要额外模型能力和成本，后置 |
| 直接集成钉钉/飞书/第三方插件 | 当前项目定位为 Docker Compose 自部署 OA，首版以自研固定模块更可控 |
| 通用自定义表单模板承载日报/周报/月报 | 固定字段更利于查询、汇总、唯一约束和导出 |

## UAT Checklist

| ID | 场景 | 预期 |
|---|---|---|
| UAT-1 | 员工创建日报草稿并提交 | 记录保存周期、提交人和部门快照，状态变为已提交 |
| UAT-2 | 员工尝试再次提交同一周期同类型记录 | 后端拒绝重复提交并返回清晰提示 |
| UAT-3 | 普通员工访问他人记录或部门汇总 | 后端拒绝访问 |
| UAT-4 | 部门负责人查看本部门周报提交情况 | 看到提交率、已提交/未提交人员和记录摘要 |
| UAT-5 | 管理员按部门、人员和日期范围筛选月报 | 列表和汇总结果口径一致 |
| UAT-6 | 授权用户按当前筛选导出 Excel | 导出文件包含明细 sheet 和汇总 sheet，且不越权 |
